# Plan 04: Cloud Sync (Supabase)

REQ-15 — cloud sync via Supabase anonymous auth. Manual push/pull. Single jsonb row per user.

**Key directives:**
- Dynamic-import @supabase/supabase-js — non-sync users see no bundle impact
- iw_sync_config localStorage key NEVER serialized into buildBackup (research §4)
- Last-write-wins by timestamp; pull shows confirmation with cloud syncedAt
- Free-tier 'project paused' error → graceful 'unavailable, using local' toast (research risk #1)
- Offline: hide sync buttons, show badge
- Single owner of App.jsx in wave 3 — no conflict
- Depends on Plans 01, 02, 03 because buildBackup must include planMode + customPlans (Plan 01) and customPlans is only meaningful with the builder (Plan 02); Plan 03 dependency is to ensure full v2 release ships intact
